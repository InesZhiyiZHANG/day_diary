# 莓好日常

一个离线优先的桌面日记小程序，记录每日计划、心情和随笔。

## 使用

- 双击 `打开小程序.lnk`，会直接用 Edge 打开小程序，不需要手动启动终端或服务器。记录保存在当前设备的浏览器中。
- 若要安装为桌面应用并启用完整离线缓存，请在此目录启动本机静态服务器，然后用浏览器打开：

  ```powershell
  python -m http.server 8000
  ```

  访问 `http://localhost:8000`，用 Edge 或 Chrome 的安装按钮添加到桌面。首次打开后，页面资源会缓存到本机；再次打开时无需网络。

## 数据

数据只存放在当前浏览器的 `localStorage` 中，不会上传。清除浏览器网站数据会同时删除记录，当前版本没有跨设备同步或自动备份。
