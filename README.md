# 莓好日常 · 共享日记

两个人一起记录计划、心情和随笔。页面仍可离线使用；联网后会与共享空间同步。

## 启动

Windows 双击 `打开小程序.lnk` 或 `打开小程序.bat`。首次使用需要 Python 3.10 或更高版本。服务会在本机后台启动，浏览器访问 `http://127.0.0.1:8765`。关闭服务可在任务管理器中结束 `python.exe` / `py.exe` 对应的 `server.py` 进程。

数据保存在 `data/shared-diary.sqlite3`，不会写进 Git 仓库。请定期在小程序的“共享日记”面板下载备份；服务端保留最近 120 个共享版本。

## 两人加入

1. 第一位成员创建共享空间，填写昵称、登录账号和至少 8 位密码。
2. 在“共享日记”面板生成邀请码，把邀请码交给另一位成员。
3. 另一位成员打开同一个服务地址，选择“我有邀请码”并创建自己的账号。
4. 页面顶部切换成员计划页。两人各有独立的计划、心情和随笔；双方都能查看和修改。每条记录会显示最近更新者。

每个空间最多两位成员。邀请码 7 天有效且只能使用一次。

## 离线和同步

登录过后，断网时仍可在本机记录。恢复连接后会自动补传。每位成员的页面分开保存，也可以互相帮忙编辑。同一页同时编辑时页面会提示冲突；不同记录会合并，同一条记录按最后保存时间保留。每个人的页面可独立选择莓果粉或晴空蓝风格。

## 在设备间共享

只在同一台电脑上启动服务，只能让该电脑访问。要让另一位成员从外网连接，服务还需要部署到可访问的主机，并通过 HTTPS 安全发布。不要把带密码的登录页面直接以普通 HTTP 暴露到公网。上线前请配置 HTTPS 反向代理或安全隧道，并将两人都指向同一个 HTTPS 地址。

## 备份旧版数据

旧版直接双击 `index.html` 时，数据位于浏览器的 `file://` 本地存储，与新版 `http://127.0.0.1:8765` 属于不同的浏览器来源。请先用旧方式打开页面，在共享空间登录页选择“导出这台设备已有记录”；再打开新版服务页面，选择“导入备份”。导入后登录/创建共享空间，记录会合并同步。
